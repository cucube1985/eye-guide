# 환자교육 그림 관리

그림 추가일: 2026-10-29

## 원고와 그림의 구분

- `../guide.md`의 질환 설명 문구는 이번 그림 추가 작업에서 변경하지 않았습니다.
- `topic-map.json`: 51개 항목마다 어떤 그림을 어떤 맥락에서 보여줄지 지정합니다.
- `anterior.json`, `retina.json`, `lens-glaucoma.json`, `supplemental.json`, `eyelids.json`, `cataract-revision.json`, `iol-history.json`, `accommodation.json`: 원본·저작자·이용 조건과 해당 원문 표시의 확인 근거를 기록합니다.
- 사진·OCT·안저 영상은 예시이며, 치료 방식이나 환자의 예후를 사진 하나로 단정하는 자료로 사용하지 않습니다.
- 시술 사진 대신 구조·치료 대상의 그림을 쓴 경우, 그 차이를 화면에 명시했습니다. 약효·시술 효과의 전후 비교인 것처럼 표시하지 않습니다.
- 영어 표기를 지우거나 한글을 덧그리지 않았습니다. 한국어 제목·설명은 이미지와 분리해 표시합니다.

## 라이선스 확인과 표시

공식 기관의 웹사이트라고 모든 이미지가 자유 이용 가능한 것은 아닙니다. NEI는 이미지 카탈로그 밖의 그림에 개별 허가가 필요할 수 있음을 [저작권 정책](https://www.nei.nih.gov/web-policies/copyright-policy)에 안내합니다.

이번에는 개별 파일에 재사용이 허용된 CC BY, CC BY-SA, 퍼블릭 도메인 자료를 선정했습니다. Commons는 원본 권리자가 아니며, [개별 파일 조건을 따라야 합니다](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia). 출처와 이용허락을 확인한 후 실제 이미지를 열어 설명과의 적합성을 검토했습니다.

각 이미지에 원작 제목, 저작자, 라이선스 링크, 원본 페이지, 변경 여부를 표시합니다. 전체 목록은 저장소 최상위의 `IMAGE_CREDITS.md`와 사이트의 `dist/IMAGE_CREDITS.md`에 생성됩니다. CC BY-SA 자료를 추후 변경할 때는 해당 이미지의 동일조건변경허락 의무도 유지해야 합니다. 기관이나 저작자의 사이트 추천·보증을 의미하지 않습니다.

## 생성과 확인

```text
npm run build
npm run check
```

원본 이미지는 `dist/images/`에 있습니다. 서버 제공 미리보기 또는 작은 원본을 저장했으며, 내용 변경 없이 화면에서 크기를 조절해 표시합니다. `build-images.mjs`가 생성하는 데이터와 크레디트에는 이미지 파일의 SHA-256도 기록됩니다. 재사용 또는 교체 시 반드시 개별 원본 페이지의 조건을 다시 확인하세요.

## 백내장·노안 그림 교체 (2026-10-29)

- 2.1 백내장: 실제 세극등 사진의 NC1·NC6 예시를 비교합니다. 인공수정체 선택 설명 안에는 두꺼운 무수정체 안경과 인공수정체 실물 사진을 배치합니다.
- 2.1.1 수술 시기: NC1·NC3·NC6 사진을 순서대로 보여줍니다. “너무 오래 미루면 생길 수 있는 문제”에는 팽대 백내장과 수술로 제거한 진행된 수정체핵 사진을 추가합니다.
- 2.2 노안: 정상 조절에서 먼 곳·가까운 곳을 볼 때 수정체 모양이 변하는 비교도로 교체합니다. 노안에서는 이런 변화가 어려워진다는 설명을 덧붙입니다.

세극등 사진은 [CC BY 4.0 공개 임상 데이터셋](https://data.mendeley.com/datasets/6wv33nbcvv/2)을 사용했습니다. 사진별 NC 등급은 [원 논문](https://www.mdpi.com/1424-8220/25/13/3954)과 연결된 전문가 선정 파일 목록을 대조했습니다. **NC는 핵 색조 등급이며 NO(핵 혼탁도)와 다릅니다. 공식 LOCS III 표준 사진판을 복제한 자료가 아닙니다.** 피질·후낭하 혼탁 전체를 평가하는 기준으로 쓰거나 사진 하나로 수술 시기를 결정하지 않습니다.

안경 사진은 2018년에 촬영한 실제 무수정체 안경입니다. 과거 교정 방식을 설명하는 예시이며 인공수정체 발명 이전에 제작된 유물로 소개하지 않습니다. 팽대 사진은 안압 상승을 증명하지 않고, 적출핵 사진은 단단한 정도를 측정하지 않습니다. 개별 이미지의 근거와 한계는 각 manifest에 보존합니다.

`topic-map.json`의 `sectionGroups`는 본문의 특정 섹션 제목에 맞춰 그림을 배치합니다. `layout: compare`는 두 장 비교, `layout: grades`는 세 장 등급 비교로 표시하며 좁은 화면에서는 세로로 이어집니다. 사용하지 않는 기존 이미지도 출처 기록은 유지합니다.

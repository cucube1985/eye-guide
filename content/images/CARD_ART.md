# 전체 안내 카드 일러스트

2026-11-04. 홈의 51개 질환·치료 카드에 연결한 자체 제작 SVG 카툰입니다. 공통 눈 캐릭터와 질환·치료의 보조 상징으로 구성했습니다. 실제 진료 사진이나 개인의 진단·병기·치료 결과를 표현하는 자료가 아닙니다.

- 그림 원본: `scripts/card-art.mjs`
- 개별 이미지: `dist/images/cards/<topic-id>.svg`
- 생성: `npm run build`
- 범위: 전체 안내 카드. 상세 설명의 임상 사진·교육 그림은 별도로 유지합니다.
- 제작: 이 프로젝트에서 직접 작성한 벡터 일러스트. 외부 이미지 복제나 AI 래스터 이미지 생성은 사용하지 않았습니다.
- 그림 이용허락: CC BY 4.0, 표시명 ‘눈에 담다 · 카드 일러스트’.

흰자 출혈은 국소 반점, 녹내장은 시신경·검사·치료, 백내장은 수정체 혼탁, 노안은 가까운 책, 망막질환은 서로 다른 층의 변화로 구분했습니다. 치료 상징에는 완치·정상화·고정 횟수의 약속을 넣지 않았습니다. 카드 이미지의 표정과 보조 상징은 탐색을 돕는 장식이며 질환명과 본문 설명을 함께 읽어야 합니다.

## 질환별 그림으로 교체 (2026-11-04)

- 공통 눈 캐릭터를 반복해 쓰던 카드 36개를 질환·치료 자체를 보여주는 그림으로 바꿨습니다. 원본은 `scripts/card-art-custom.mjs`이며 `card-art.mjs`가 우선 사용합니다.
- 전안부: 결막염(충혈된 눈), 알레르기(돼지풀·꽃가루·집먼지진드기), 감염성(결막 세포 위의 바이러스·세균), 절개(병변과 날), 결막하출혈, 눈물흐름(눈물 고임과 막힌 눈물길), 안구건조증(눈물 3층), IPL(감은 눈 아래 레이저 팁), 익상편, 콘택트렌즈 각막염(세균·가시아메바·진균).

- 녹내장·망막(3.1~4.8): 눈 캐릭터 없이 시신경·검사·치료·망막 단면·안저 그림으로 표현.
- 소아: 근시(흐린 칠판), 약시(가림 패치), 사시(안쪽으로 몰린 눈).
- 목록에 없는 카드(1.2 다래끼 등)는 기존 그림을 유지합니다.
